# Português, inglês e espanhol

A Academy inteira troca de idioma: a home, o menu do aluno, as telas, as
ferramentas, o conteúdo da Biblioteca e do Dojo, o que o time cadastra no
banco e os e-mails transacionais.

Este documento é para quem vai mexer nisso depois. Ele responde três
perguntas: onde a frase mora, como uma frase nova entra e o que fazer quando
uma tradução sai errada.

## A regra que vale para tudo

**Frase sem tradução aparece em português.** Nunca a chave crua, nunca campo
vazio, nunca tela quebrada. É por isso que a chave do dicionário é o próprio
texto em português, e não um código como `menu.botao.salvar`: quem abre o
componente continua lendo a frase inteira, e quem esquece de traduzir só
entrega uma linha em português no meio de uma tela em inglês — feio, mas
legível e óbvio de achar.

O português é a fonte da verdade. Corrigir o português é mexer em um lugar;
o inglês e o espanhol vêm atrás.

## Onde cada frase mora

| O que é | Onde está | Como a tela pega |
| --- | --- | --- |
| Home e site público | `lib/i18n/dictionaries.ts` | `useT()` |
| Menu e casca do aluno | `lib/i18n/textos.ts` | `textos(idioma)` |
| Texto das telas | `lib/i18n/frases-geradas.ts` | `tr("...")` |
| Biblioteca, Dojo, mascote | os próprios arquivos de dados | `tr(item.campo)` |
| Curso, aula, live, material | tabela `content_translations` | `listaTraduzida(...)` |
| E-mails | `lib/i18n/frases-geradas.ts` | `f("...")` |

Os dois primeiros são dicionários tipados: o TypeScript reclama se faltar uma
chave em um idioma. Os outros caem no português quando falta.

### `tr` no servidor e no navegador

São duas funções com o mesmo nome e o mesmo dicionário:

- Tela de servidor: `import { tr } from "@/lib/i18n/traduzir-servidor"`. Lê o
  cookie da requisição, então a página já nasce traduzida.
- Tela de navegador: `const tr = usarTraducao()`, dentro do componente.

O segundo é um hook de propósito. Um valor de módulo seria mais cômodo, mas o
componente de navegador também renderiza no servidor, e lá o módulo é
compartilhado entre requisições: duas pessoas em idiomas diferentes no mesmo
instante receberiam o texto uma da outra.

## Como entra uma frase nova

Escreva já com `tr("...")` e rode:

```bash
python scripts/i18n.py --extrair app/conta/minha-tela/page.tsx
python scripts/i18n.py --traduzir
npm run test:i18n
```

O `--extrair` junta as frases em `lib/i18n/frases-pendentes.json`, o
`--traduzir` preenche `frases-geradas.ts` usando a Groq com glossário técnico,
e o teste confere que toda chave usada existe no dicionário.

Se a tela já estava escrita sem `tr`, o `--aplicar` envolve o texto entre tags
e os atributos de texto visível. Ele é conservador: o que tem expressão,
chave ou tag dentro fica como está, para ser feito à mão.

O `--traduzir` esbarra no limite por minuto da Groq e espera sozinho. Lote
pequeno anda mais rápido do que lote grande: `I18N_LOTE=8` se estiver
apanhando muito.

## Quando a tradução sai errada

Não edite `frases-geradas.ts`: ele é reescrito pelo script. A correção
revisada entra em `CORRECOES`, dentro de `lib/i18n/frases.ts`, e vence a
automática.

```ts
const CORRECOES: Record<string, Partial<Par>> = {
  // "Revisar" é revisar de novo; o botão manda conferir a resposta.
  "Conferir": { es: "Comprobar" },
};
```

Para o conteúdo do banco, a correção é em `/admin/traducoes`: salvar marca o
campo como revisado por gente, e o botão "Traduzir com IA" nunca sobrescreve
o que uma pessoa corrigiu.

## Decisões que parecem detalhe e não são

**A busca da Biblioteca procura no texto traduzido.** Quem lê em inglês digita
"running total", não "acumulado". Sem isso, o acervo inteiro parecia vazio. O
português continua na busca porque nome de função é igual nos três idiomas.

**Os nomes das colunas da base do Dojo ficam em português.** Eles aparecem
dentro das fórmulas do gabarito; traduzir o cabeçalho quebraria a resposta.

**A correção do Dojo monta a lista do que faltou fora da frase.** Molde com
lacuna (`"a fórmula não usa {x}"`) volta da tradução com a lacuna no lugar
errado, e aí a frase quebra em vez de só ficar estranha.

**Nome próprio não se traduz.** Arena SQL, Forja DAX, Caixa-Preta,
DriveCanvas, Knowledge Universe. "Biblioteca de referência" e "O número não
bate" são descrição, e descrição se traduz.

## Onde o idioma é guardado

O cookie `lang` resolve a tela: chega com a requisição e o servidor renderiza
no idioma certo, sem piscar.

`profiles.locale` resolve o que acontece sem navegador. Quando o pagamento
confirma às três da manhã, não existe cookie nenhum na história — o e-mail
sai no idioma que a pessoa escolheu da última vez. A coluna já existia no
schema, com default `'pt'`, e estava sem uso.

Na primeira visita em um aparelho novo, sem cookie, a área do aluno usa o
perfil como palpite e o seletor grava o cookie assim que a tela abre.
